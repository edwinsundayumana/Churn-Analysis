# SQL Querie

This folder contains the SQL exploration used to identify churn drivers before building predictive models.

**File:** churn_exploration_queries.sql

**What it does:**
- Confirms dataset row count and cleans a data quality issue (blank TotalCharges for zero-tenure customers)
- Calculates overall churn rate
- Breaks down churn by contract type, tenure bracket, monthly/total charges, internet service type, payment method, and online security subscription
